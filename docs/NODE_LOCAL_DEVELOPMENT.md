# Graphite Local — запуск, обновление и перезапуск на Windows

**Это рабочая инструкция для локального Graphite + приватного ChatGPT-плагина «Graphite Local».**
Локальный Node.js слушает только `127.0.0.1:8788`, использует SQLite
`%USERPROFILE%\.graphite-local\graphite-dev.sqlite` и передаёт MCP-запросы
в ChatGPT через отдельный Secure MCP Tunnel. ПК и оба процесса должны работать.
Существующие опубликованные Site, D1 и связанный с ними плагин не затрагиваются.

**Здесь нет автоматического обновления или фонового запуска.** Перед обновлением
сохрани изменения в браузерном редакторе, дождись завершения вызовов ChatGPT
и останови Node/tunnel через `Ctrl+C`. Не запускай второй сервер на том же порте.
Актуальная реализация — GitHub `telldrasilo/plot-architect`, `main`.

## 1. Обычное обновление и перезапуск (тот же PowerShell)

Подходит, если окно PowerShell, в котором был запущен
`npm.cmd run dev:node-tunnel`, **остаётся открытым**. После `Ctrl+C`
переменные окружения `GRAPHITE_TUNNEL_CLIENT_EXE`,
`GRAPHITE_TUNNEL_ID` и `CONTROL_PLANE_API_KEY` остаются в этом сеансе.

1. Сохрани работу в редакторе и дождись завершения MCP-операций.
2. Нажми `Ctrl+C` в работающем PowerShell и дождись приглашения `PS ...>`.
3. Вставь весь блок:

```powershell
cd D:\Graphite\plot-architect
git switch main
git pull --ff-only
cd site
npm.cmd run dev:node-tunnel
```

4. **Оставь PowerShell открытым.** Открой
   [Graphite](http://127.0.0.1:8788/) в том же профиле Chrome.
   Повторный вход не нужен, пока действительна сохранённая сессия (до 30 дней).
5. В ChatGPT используй **уже подключённый** плагин «Graphite Local»:
   попроси вызвать `list_projects`. **Не создавай заново туннель или плагин.**

**Признаки готовности:** в консоли появились `Graphite LOCAL NODE` и
`Graphite Local tunnel started`; туннель установил рабочий polling
(возможно, после временных сетевых ошибок); редактор открывается по
`http://127.0.0.1:8788/`; `list_projects` возвращает проекты.
Строка «tunnel-client started» сама по себе ещё не доказывает доступность
MCP: подтверждение — успешный вызов инструмента.

## 2. Если PowerShell закрыт: новый терминал

**Браузерный вход сохранён, но ключ OpenAI Platform не сохраняется**
в конфигурации Graphite. Поэтому новый PowerShell потребует передать
runtime API key заново. Нужен Secret API key OpenAI Platform с правами
**Tunnels: Read, Use**, а не Tracking ID. Не печатай его и не добавляй
в .ps1, GitHub, конфиг плагина или переписку. Если полный секрет больше
нельзя получить, потребуется создать новый ключ в OpenAI Platform.
Автоматизированное хранение через Windows Credential Manager пока
**не реализовано**.

1. Открой PowerShell на своём компьютере.
2. Скопируй Secret API key в буфер обмена. Используй только доверенный ПК.
3. Выполни блок ниже, **заменив один placeholder**
   `tunnel_ВСТАВЬ_СВОЙ_ID` на ID уже созданного приватного Graphite Local
   (ID не секрет, но его не нужно публиковать в репозитории):

```powershell
cd D:\Graphite\plot-architect
git switch main
git pull --ff-only

$env:GRAPHITE_TUNNEL_CLIENT_EXE = 'D:\Graphite\tunnel-client\tunnel-client.exe'
$env:GRAPHITE_TUNNEL_ID = 'tunnel_ВСТАВЬ_СВОЙ_ID'

# Ключ считывается из буфера; не вставляй его текст в команду.
$candidate = ([string](Get-Clipboard -Raw)).Trim()
if ($candidate -notmatch '^sk-\S{30,}$') {
    Remove-Variable candidate -ErrorAction SilentlyContinue
    throw 'Буфер пуст или там не Secret API key (sk-...).'
}
$env:CONTROL_PLANE_API_KEY = $candidate
Remove-Variable candidate
Set-Clipboard -Value ' '

# Выводим только True/False, никогда не сам ключ.
$clientOK = Test-Path $env:GRAPHITE_TUNNEL_CLIENT_EXE -PathType Leaf
$tunnelOK = $env:GRAPHITE_TUNNEL_ID -match '^tunnel_[A-Za-z0-9_]{20,100}$'
$keyOK = $env:CONTROL_PLANE_API_KEY -match '^sk-\S{30,}$'
Write-Host "Tunnel client: $clientOK"
Write-Host "Tunnel ID:     $tunnelOK"
Write-Host "API key:       $keyOK"
if (-not ($clientOK -and $tunnelOK -and $keyOK)) {
    throw 'Настройки туннеля неполные — сервер не запускаем.'
}

cd site
npm.cmd run dev:node-tunnel
```

4. Убедись, что три проверки дали `True`, сервер и туннель
   запустились; затем открой редактор и проверь `list_projects` в ChatGPT.
   Старый приватный плагин «Graphite Local» продолжит работать с тем же
   ID туннеля.
5. Буфер очищен командой `Set-Clipboard`. Для следующего **нового**
   терминала снова потребуется доступ к Secret API key.

Если `Read-Host -AsSecureString` не передаёт ключ в переменную, используй
описанный выше уже проверенный ввод через буфер. Не присылай секреты
или временный локальный токен в чат.

## 3. Первый запуск браузера и повторный вход

После первого входа в `http://127.0.0.1:8788/` с временным ключом
из **локального** PowerShell Chrome хранит HttpOnly, SameSite=Strict cookie
до **30 дней**. Она переживает `git pull` и перезапуск Node.js в том же
браузерном профиле. Cookie и разрешённые сессии не равны MCP-ключу:
локальный Bearer-токен **всегда генерируется заново при запуске**,
но дочерний MCP-мост получает его автоматически — вводить его в ChatGPT
или конфигурацию туннеля вручную не нужно.

Сессии хранятся в отдельном файле
`%USERPROFILE%\.graphite-local\browser-sessions.json`: только SHA-256
хеши случайных cookie ID и сроки истечения, не сами cookie или ключи.
Сюжеты остаются в `graphite-dev.sqlite`. Обычный `git pull` не стирает
ни один из этих файлов. **Новый браузерный профиль, инкогнито, очищенные
cookie, выход из редактора или истёкшие 30 дней** требуют снова ввести
*новый временный локальный ключ* из работающего PowerShell. Сеанс
после штатного выхода отзывается даже после перезапуска сервера.
Повреждённый файл сессий блокирует запуск, а не приводит к незаметному
сбросу авторизации. Не коммить эти файлы и не открывай к ним доступ
другим учётным записям.

## 4. Рабочий цикл: авторская заметка → черновики

1. В браузерном Graphite создай заметку с конкретным заданием.
   Сохрани проект.
2. В ChatGPT обратись к приватному плагину «Graphite Local» и попроси
   обработать заметку. ChatGPT вызывает `list_note_tasks` и
   `get_note_task`, получает ревизию, текст и допустимый связанный контекст.
3. По смыслу задания определяется **одно решение или несколько
   альтернатив**, число нод и типы внутренних связей. Нельзя
   принудительно дробить ответ на три варианта.
4. `preview_note_drafts` проверяет структуру **без записи** и выдаёт
   `review_token`. После согласия автора `save_note_drafts` сохраняет
   черновики в **отдельной рабочей области заметки**; это не канон.
5. Вернись в браузер и открой актуальную ревизию проекта. Автор может
   изучать, редактировать, отклонять черновики и отдельно принимать
   выбранные ноды в основной сюжет.

Для локального owner-only запуска этот workflow включён. Он проверяет
ревизию и согласованный preview, защищает канонический граф и не
переписывает исходную заметку. Обычный `apply_patch` создаёт или меняет
**канонические** элементы и не заменяет процесс `save_note_drafts`.
Hosted Worker по умолчанию оставляет workflow выключенным; изменения
локальной настройки не публикуют Site.

## 5. Диагностика и безопасная остановка

| Симптом | Действие |
| --- | --- |
| `Unable to prepare ...` или ошибка Git | Проверь `git status --short` и ветку `git branch --show-current`; не делай force-pull/reset с пользовательскими изменениями. |
| `Set GRAPHITE_TUNNEL_CLIENT_EXE ...` | Новый PowerShell не унаследовал runtime-переменные; выполни `2. |
| `CONTROL_PLANE_API_KEY` пустой | Проверь только `$keyOK` (True/False); передай Secret API key заново, не раскрывая его. |
| `EOF` / `network_error` в начале | Возможно, временный сетевой сбой; проверь восстановление polling. Если ошибки продолжаются, проверь доступность OpenAI Platform и состояние сети. |
| `403` на форме входа | Открой `http://127.0.0.1:8788/` (а не `localhost`), используй форму с Origin браузера. |
| Появилась форма логина | Проверь профиль, cookie, 30-дневный срок; при необходимости введи локальный ключ нового процесса. |
| `WORKFLOW_DISABLED` | Проверь, что запущен актуальный `main` через `npm.cmd run dev:node-tunnel` и workflow не переопределён в отдельном экспериментальном сервере. |
| Порт 8788 занят | Останови старый процесс через `Ctrl+C`; не поднимай второй экземпляр. |

Сервер и tunnel-client живут в одном PowerShell. `Ctrl+C` завершает
локальный сервер и дочерний туннель; браузерная сессия и SQLite остаются
на диске. Не прерывай выполнение во время записи. Никогда не удаляй
`graphite-dev.sqlite`, `browser-sessions.json` или WAL-файлы ради
«исправления» обычного сбоя запуска.

**После обновления зависимостей**, а не при каждом перезапуске, можно
выполнить из `D:\Graphite\plot-architect\site`:

```powershell
npm.cmd ci
npm.cmd run test:browser-sessions
npm.cmd run test:note-local
npm.cmd run test:mcp-bridge
```

Это синтетические тесты; реальные локальные проекты они не меняют.
Для работы редактора **без** ChatGPT-туннеля доступен отдельный
`npm.cmd run dev:node-local` — нельзя запускать одновременно с
`dev:node-tunnel` на том же порте. Сменить локальный порт можно через
`$env:GRAPHITE_LOCAL_PORT = '8789'`, но для обычной работы оставляй
`8788`. CLI использует `npm.cmd`, чтобы избежать блокировки
`npm.ps1` политикой PowerShell.

## 6. Первичная настройка на новом компьютере (однократно)

Нужны Windows PowerShell, Node.js 22+, Git, каталог
`D:\Graphite\plot-architect`, официальный
`D:\Graphite\tunnel-client\tunnel-client.exe`, отдельный приватный
Platform Tunnel и **отдельный приватный плагин** «Graphite Local»,
подключённый к этому туннелю (не к синтетическому «Graphite MCP Probe»).
Инструменты Graphite используют stdio-мост
`site/scripts/mcp-local-stdio.mjs`, который пересылает запросы только
на `http://127.0.0.1:8788/mcp` с временным Bearer-ключом. Клиент
трансляции получает секреты через переменные окружения, а не через
аргументы процесса, GitHub, Site или настройки плагина. Для нового
компьютера установи npm-зависимости один раз:

```powershell
cd D:\Graphite\plot-architect\site
npm.cmd ci
npm.cmd run test:mcp-bridge
```

Затем используй `2` для подключения нового терминала и `1` для
обычных обновлений. Плагин не нужно пересоздавать при каждом
`git pull`. Для первого подтверждения связи безопасен
`list_projects` (чтение); `create_project` — только по прямому
согласию владельца.

## 7. Границы безопасности

**Только личный ПК и закрытый loopback.** Не делай порт публичным,
не подключай Secure MCP Tunnel напрямую к открытому HTTP, не
разворачивай этот Node-шлюз на VPS. Он не имеет полноценной удалённой
OAuth/TLS-модели. HTTP-шлюз проверяет Host, Origin, cookie для браузера
и Bearer для MCP; их нельзя смешивать. Он не доверяет входящему
`oai-authenticated-user-id`, выставляет локальную идентичность
только после авторизации.

SQLite хранится на ПК, но выбранный для передачи по MCP контекст
проходит через инфраструктуру OpenAI. Модельные OpenAI API-вызовы
этот Node-сервер не делает; Platform runtime key используется
для туннеля. Не пересылай ключи и пользовательские сюжеты в GitHub.
Нет автоматического резервного копирования: сохранение сессии
**не является резервной копией сюжетов**.

Для Beget потребуется отдельный проект развёртывания с TLS,
проверенной авторизацией браузера, OAuth для MCP, безопасной работой
с секретами, резервным копированием и восстановлением. Публикация
Site, изменение production D1 или существующего MCP-плагина
в этот рабочий цикл не входят. См. также
`/Планировщик сюжета/Development/GRAPHITE_BEGET_MCP_PLAN.md` в Library.
